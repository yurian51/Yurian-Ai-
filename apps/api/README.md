# API Application

Target: NestJS + TypeScript.

Responsibilities:
- authentication and authorization
- tenant/workspace context resolution
- domain modules and application services
- AI orchestration
- provider adapters
- tool registry and execution
- memory and knowledge APIs
- approvals and audit events
- WebSockets, REST and webhooks

All resource access must be tenant-aware. Domain logic must not depend on browser concerns or provider-specific SDKs.
